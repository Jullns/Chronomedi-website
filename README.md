# Chronomedi-website
Além de apresentar a proposta e a problemática que motivaram o desenvolvimento do projeto, o site busca demonstrar as principais funcionalidades da solução, como os alertas de medicamentos, organização dos compartimentos, acompanhamento das doses e integração entre a caixa e o aplicativo.
O site também tem a finalidade de divulgar a Chronomedi como uma solução tecnológica, apresentar sua missão, seus valores e sua equipe de desenvolvimento, além de disponibilizar informações sobre segurança, privacidade e proteção dos dados dos usuários.

# Setup & Instalação
Clone o repositório para o seu computador:

`gh repo clone Jullns/Chronomedi-website`

Vá para a pasta do projeto: 
* cd site-noticias-norteBrasil

Abra o arquivo principal:
* Abra a pasta do projeto no seu editor de código (como o VS Code) e execute a extensão Live Server, ou abra o arquivo index.html direto no seu navegador favorito.
